ZuperTalk
วิทยุสื่อสารบนมือถือ — กดค้างเพื่อพูด ใช้ได้แม้จอดับ ล็อกเครื่อง หรือปัดแอปทิ้ง
เวอร์ชันล่าสุด ⬇︎ ดาวน์โหลด Android
ขนาด ~30 MB · Android 7 ขึ้นไป (64-bit)
เปิดหน้านี้จากคอม? สแกนด้วยมือถือ
  1. แตะไฟล์ ZuperTalk.apk ที่ดาวน์โหลดมา → ติดตั้ง (ถ้าเครื่องถาม ให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก")
  2. มีรุ่นเก่าอยู่แล้ว → กด อัปเดต ได้เลย · ถ้าขึ้นว่า "แพ็กเกจขัดแย้งกับแพ็กเกจที่มีอยู่" หรือ "ติดตั้งไม่ได้" แปลว่าเครื่องมีรุ่นทดสอบเก่า ให้ถอนการติดตั้งแอปเดิมก่อนครั้งเดียว แล้วแตะไฟล์ใหม่
  3. เปิดแอป ใส่ รหัสทีม (ขอจากหัวหน้าทีม) + ชื่อช่อง + ชื่อตัวเอง → เข้าช่อง
⚙️ ตั้งครั้งเดียว ให้ใช้ได้ตอนจอดับ
OPPO / Realme: ตั้งค่า → แอป → ZuperTalk → การใช้แบตเตอรี่ → อนุญาตทำงานเบื้องหลัง
Honor / Huawei: ตั้งค่า → แบตเตอรี่ → การเปิดแอป → ZuperTalk → จัดการด้วยตนเอง (เปิดครบ 3 ช่อง)
Samsung: ตั้งค่า → แอป → ZuperTalk → แบตเตอรี่ → ไม่จำกัด
รุ่นอื่น: iPhone (ยังไม่มี)
